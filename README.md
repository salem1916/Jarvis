# Jarvis

## Set up Jarvis on Windows

1. Download `Jarvis-Windows-Setup.zip` from the [latest Windows setup release](https://github.com/salem1916/Jarvis/releases/latest).
2. Extract the ZIP, open `START HERE.txt`, and run `Setup-Jarvis.cmd` after installing Git for Windows if needed.
3. Open the JARVIS desktop shortcut. The setup guide covers Ollama, Hermes, and voice.

The setup uses the [current desktop development branch](https://github.com/salem1916/Jarvis/tree/experiment/grounded-browser-planner), which contains the browser and voice updates.
